# PQ COMMAND Design System

The PQ COMMAND design system is based on four core palette anchors:

- Obsidian for page background and deep surfaces.
- Ivory and white for readable content layers.
- Champagne-gold for restrained emphasis, focus, and premium accents.
- Limited semantic tones for status and feedback.

## Principles

- Gold remains an accent, never a dominant page fill.
- Focus states are visible on all interactive controls.
- Reduced-motion users should not lose information or affordance.
- Components are semantic first and dependency-light.
- Future screens inherit global tokens from `src/app/globals.css` and shared values from `src/lib/design-tokens.ts`.
